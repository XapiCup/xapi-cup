1. Équipes inscrites

Saisissez les noms des équipes. La liste se sauvegarde automatiquement et est synchronisée avec la page publique.

Astuce : appuyez sur Entrée pour ajouter rapidement.

2. Poules & matchs

Définissez le nombre de poules, puis générez le tirage. Les poules sont équilibrées et l'ordre des matchs est mélangé.

Le tirage répartit les équipes de manière équilibrée (écart max 1).

3. Qualification vers la phase finale

Choisissez combien d'équipes par poule se qualifient, et si la consolante est activée. Vous pourrez modifier manuellement les qualifiés avant de lancer les arbres.

Si activée, les équipes non-qualifiées jouent aussi un arbre à part.

4. Phase finale

Cliquez sur un match pour saisir le score et désigner le vainqueur. Les vainqueurs sont automatiquement propagés au tour suivant.

5. Export & sauvegarde

Exportez l'arbre final en image, ou téléchargez une sauvegarde complète du tournoi (au format JSON).
